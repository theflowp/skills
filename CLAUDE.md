# Repo conventions

This is a **public** repository of Agent Skills.

## Language

Everything in this repo is written in **English**: `SKILL.md` files, references, file and folder names, code identifiers, comments, UI strings, example content, commit messages. When importing a skill written in another language, translate it fully, including paths and identifiers, rather than leaving parts in the original.

## Layout

- One skill per folder under `skills/<name>/`, with `name:` in the `SKILL.md` frontmatter matching the folder name (kebab-case).
- Add every new skill to the table in `README.md` and as a plugin in `.claude-plugin/marketplace.json`.

## Public by default

Before adding or changing anything, check that it contains no private data: real names of people other than public sources, company or client names, internal URLs, hostnames, database names, credentials, tokens, or anything tied to a private project. Replace them with neutral placeholders (`Your Name · Your Company`, `example.com`).

Never commit build output, `node_modules/`, screenshots generated by the skills, or `.DS_Store` files.
